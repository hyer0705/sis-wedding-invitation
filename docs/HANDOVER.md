### 되돌리기 전에 알아야 할 결정 3가지

1. **When&Where 그린 카드가 사라졌다.** 고객이 달력·일시·장소·D-Day 를 한 카드로 합치기로 확정했다(2026-08-11, 시안 확인 후). **이제 페이지에 `--primary` 배경 카드가 하나도 없다** — 그린 악센트는 섹션 타이틀과 D-Day 「초」 박스뿐이다. c안에서 눈에 띄게 벗어나는 변경이라, 아직 **고객이 실제 화면을 못 봤다**(프리뷰 401, 아래 참고).
2. **`--shadow-green-card` 와 `--on-primary-title` 토큰이 미사용이 됐다.** 그린 카드 전용이었다. 지우지 않고 뒀다 — 되돌릴 여지를 남기려는 것이다.
3. **시간 세는 일은 `useCountdown` 훅이 한다**(`DDay.tsx`). Calendar 와 DDay 가 **같은 값을 봐야** 한다 — 예식이 지나면 「캘린더에 저장」 버튼을 감춰야 하는데, 각자 타이머를 돌리면 자정을 넘길 때 한쪽만 갱신돼 버튼이 남는다.

### 검토에서 고친 5건

`/code-review` 지적이다. 되살아나기 쉬우니 적어 둔다.

- 320px 에서 예식 일시가 `…오전 11` / `시` 로 끊겨 **마지막 한 글자만 다음 줄**에 남던 문제 → 날짜와 시각을 각각 `inline-block` 으로 묶어 덩어리째로만 갈라지게. **`word-break: keep-all` 만으로는 부족했다** — 320px 은 애초에 한 줄에 안 들어간다
- `.ics` 의 `METHOD:PUBLISH` 제거 — 적어 두면 RFC 5546 상 `ORGANIZER` 가 필수가 되는데 우리에겐 주최자 주소가 없다
- `URL` 은 URI 타입이라 TEXT 이스케이프를 걷어냄
- 예식 이후 「캘린더에 저장」 버튼 숨김 (페이지는 예식 후 한 달 유지, `CM-08`)
- 테스트에서 `URL.revokeObjectURL` 을 지우지 않는다 — `downloadIcs` 가 남긴 1초 타이머가 뒤늦게 깨어난다

## 함정 — 코드만 봐서는 모르는 것

### 이번에 새로 확인한 것

- **`npm run check` 는 E2E 를 돌리지 않는다.** 유닛·타입·빌드까지다. DOM 구조를 바꿨으면 `npm run test:e2e` 를 따로 돌려야 한다 — 이번에 320px 줄바꿈 문제를 잡아낸 것이 E2E 였다
- **axe 는 `color-contrast` 를 제외하고 돈다**(`e2e/smoke.spec.ts`). 그래서 **대비 위반은 CI 가 잡지 못한다.** 달력의 예식일 원(`--on-primary` on `--primary`, 14.5px)은 3.24:1 로 AA 미달이지만 고객이 이 모양을 택했다. 요일 헤더는 `--muted-2`(2.65:1) 대신 **`--text-sub`(4.52:1)** 를 쓴 이유가 이것이다
- **Testing Library 의 `getByText` 는 자식 엘리먼트로 쪼개진 텍스트를 못 찾는다.** 예식 일시를 `<span>` 둘로 나눈 순간 `getByText("전체 문자열")` 이 깨졌다. 조각별로 찾아야 한다
- **`git mv` 로 옮겨도 내용이 많이 바뀌면 git 은 「삭제 + 신규」로 기록한다.** 파일 삭제는 승인 필수라(CLAUDE.md 절대규칙 4) 커밋 전에 `git status` 로 확인할 것

### 이전부터 유효한 것

- **`.env` 를 고치면 dev 서버를 반드시 재시작한다.** Vite 는 시작 시 한 번만 읽는다
- **카카오 도메인 미등록은 콘솔에 아무 흔적도 남기지 않는다** — 401 JSON 을 브라우저가 `ERR_BLOCKED_BY_ORB` 로 버린다. 원인을 보려면 Playwright `page.route` + `route.fetch` 로 응답 본문을 가로챈다
- **Vercel 프리뷰 주소는 두 종류.** 배포 해시 URL 은 커밋마다 바뀌어 카카오에 등록할 수 없다. `...-git-<브랜치>-...` 별칭만 가능
- **카카오 지도는 페이지 스크롤을 삼킨다** — 투명 덮개를 위에 올려야 한다 (`Location.tsx`)
- **인앱 미리보기 브라우저로는 스크롤을 검증할 수 없다.** Playwright 로 할 것
- **`VITE_` 값은 빌드 시점에 번들에 박힌다.** Production·Preview·Development 세 환경 모두 설정
- **`package-lock.json` 을 재생성하지 말 것** (sharp 네이티브 바이너리, `docs/WORKFLOW.md` §7)
- dry-run 은 `npm run upload:images -- --dry-run` (`--` 없으면 npm 이 플래그를 먹는다)
