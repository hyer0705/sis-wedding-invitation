# 기능 ID ↔ Linear 이슈 매핑

고객이 채운 「기능 요구사항 명세서」의 채택 결과를 Linear 이슈에 연결한 표다.
고객이 기능 ID로 문의하면 여기서 담당 이슈를 찾는다.

**기준일**: 2026-08-04 · **채택 42건 / 전체 55건**

> 명세서(Google Sheets)가 단일 기준이다. 코드나 c안 시안이 명세서와 다르면 **명세서를 따른다.**

| 항목 | 상태 | 막힌 이슈 |
|---|---|---|
| 인사말 본문 (`IN-01`, 필수) | 작성중 | SIS-8 부분 진행 |
| 신랑 어머니 성함 (`IN-03`, 필수) | 작성중 | SIS-8 부분 진행 |
| 예식 안내 문구 (`NT-01`) | 작성중 | **SIS-14 Blocked** |

| 배경음악 파일 | 시트는 '제출완료'지만 **리포에 없음** | **SIS-27 Blocked** |
| 파비콘 | 미제출 | — |
| 예식장 안내문 · 문구 원고 | 준비중 | SIS-14 |

## 고객 재확인이 필요한 모순

1. **예식 일시** — 명세서 첫 시트 헤더는 "2026년 12월 6일", 입력 시트·공유 카드 설명은 "2027년 1월 24일". **입력 시트를 채택**했다
2. **예식장 표기** — "웨스턴베니스" / "웨스턴베니비스"로 흔들림
3. **연락처** — `CT-01·02·03`을 전부 미채택했는데 입력 시트에는 휴대폰 번호가 채워져 있음. **미채택을 따른다**
4. **`GL-02`** — 채택(O)인데 비고는 "확대 및 줌 거절". 라이트박스는 유지하되 핀치 줌만 제외로 해석 중
5. **RSVP "전하고 싶은 말"** — c안 폼에는 있으나 시트 「수집 항목」에는 없음
