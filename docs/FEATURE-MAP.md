# 기능 ID ↔ Linear 이슈 매핑

**기준일**: 2026-08-11 · **채택 41건 / 전체 55건**

2026-08-06 갱신: `GL-02`(확대 보기)가 고객 확정으로 **채택 → 미채택**이 됐다. 시트 `H`열도 `X`로 고쳐야 한다.

2026-08-11 갱신: `IN-01`~`IN-04`(SIS-8)이 전부 풀렸다. 인사말·인용구를 수령했고 신랑 어머니는 표기하지 않기로 확정했다. 채택 여부가 바뀐 기능은 없다.

## 이 문서의 위치 — 시트가 단일 기준이다

기능 채택 여부와 고객 정보의 **단일 기준은 Google Sheets 「기능 요구사항 명세서」**다. 이 문서는 거기서 파생된 스냅샷이며, **둘이 다르면 시트가 이긴다.**

그럼에도 리포에 이 문서를 두는 이유는 셋이다.

1. **세션마다 시트를 왕복하지 않기 위해서.** `CLAUDE.md`가 이 문서를 링크하고 있어 작업 시작 시 맥락에 자동으로 들어온다. "이 기능 채택됐나?"를 확인하려고 매번 Drive를 호출할 필요가 없다
2. **시트에 담기지 않는 판단을 남기기 위해서.** 예를 들어 `GL-04`는 미채택이지만 구현은 유지한다. 이런 결정과 근거는 시트에 적을 자리가 없다
3. **어느 시점 기준으로 개발했는지 남기기 위해서.** 시트는 고객이 계속 고치므로, 나중에 어긋났을 때 무엇이 언제 바뀌었는지 추적할 수 있어야 한다

## 시트 구조

### 「기능 요구사항 명세서」

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| ID | **Linear 이슈** | 대분류 | 기능명 | 상세 요구사항 | 우선순위 | 준비 항목 | **채택 여부** | 현재 구현 여부 | 개발 상태 | 비고 |

`B`(Linear 이슈)는 아래 §채택 기능·§미채택 기능 표의 값과 같아야 한다. 티켓이 바뀌면 양쪽을 함께 고친다.

### 「신랑신부 정보 입력」

| A | B | C | D | E | F | G | H | I | J |
|---|---|---|---|---|---|---|---|---|---|
| 구분 | 입력 항목 | 작성 가이드 | 입력란 | 필수 | 관련 기능 ID | **Linear 티켓** | 작성 완료 | **채택** | **확인** |

`G`·`I`·`J` 세 열은 손으로 적지 않고 명세서 시트에서 수식으로 끌어온다. 시트를 새로 만들거나 수식이 깨졌을 때를 대비해 아래에 보관한다. (첫 데이터 행이 4행인 경우 기준)

```
G4  =IFERROR(INDEX('기능 요구사항 명세서'!$B:$B, MATCH($F4,'기능 요구사항 명세서'!$A:$A,0)), "—")
I4  =IFERROR(INDEX('기능 요구사항 명세서'!$H:$H, MATCH($F4,'기능 요구사항 명세서'!$A:$A,0)), "—")
J4  =IF($F4="","", IF($I4<>"O","불필요", IF($H4="불필요","불필요", IF(TRIM($D4)="","⚠ 빈칸", IF(OR($D4="미정",$H4="작성중"),"⏳ 확정 대기","✓")))))
```

조건부 서식(맞춤 수식): `=$J4="⚠ 빈칸"` → 노란 배경 / `=$J4="불필요"` → 회색 배경.

이 구조의 값어치는 **채울 필요가 없는 칸을 회색으로 걷어내는 것**이다. 연락처 6칸은 `CT-01·02·03`을 미채택해 이미 채워졌어도 쓰지 않는다.

### `H`(작성 완료)의 `불필요`

`I`(채택)는 **기능 ID 단위**라, 채택된 기능 안의 특정 입력 항목만 쓰지 않기로 한 경우를 표현하지 못한다. 이때는 `H`에 `불필요`를 직접 적는다 — `J`가 회색 처리한다.

현재 해당하는 항목: **영문 표기** (`CV-01`은 채택이지만 국문만 쓰기로 확정, 2026-08-04)

## 고객 재확인이 필요한 모순

1. **예식 일시** — 명세서 첫 시트 헤더는 "2026년 12월 6일", 입력 시트·공유 카드 설명은 "2027년 1월 24일". **입력 시트를 채택**했다
2. **예식장 표기** — "웨스턴베니스" / "웨스턴베니비스"로 흔들림
3. **연락처** — `CT-01·02·03`을 전부 미채택했는데 입력 시트에는 휴대폰 번호가 채워져 있음. **미채택을 따른다**
4. ~~**`GL-02`** — 채택(O)인데 비고는 "확대 및 줌 거절"~~ → **해소(2026-08-06).** 확대 자체를 뺀다. 시트 `H`열을 `X`로 갱신할 것
5. **RSVP "전하고 싶은 말"** — c안 폼에는 있으나 시트 「수집 항목」에는 없음
